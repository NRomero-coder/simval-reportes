# Notas de las pruebas

Cada archivo `<prueba>__<sala>.md` es la nota de una prueba y se muestra en todos los
reportes donde esa prueba tiene diferencias. Se escriben desde la página («escribir
motivo» / «editar») con el editor de GitHub; simval no las modifica.

Formato: unas líneas `clave: valor`, una línea en blanco y el texto libre.

    estado: causa encontrada
    campaña: diario_20261109_133937

    Texto del motivo...

Estados: sin investigar, investigando, causa encontrada, esperado, corregido.
